# Flighter Pilot

Endless top-down air combat in the browser. Take off in a biplane, shoot down waves of enemy planes, spend your prize money on upgrades, and climb the eras all the way to a stealth fighter.

**Play:** https://jdmrt.github.io/Flighter-Pilot/

## Install it like an app
- **iPhone (Safari):** open the link, tap **Share**, then **Add to Home Screen**.
- **Android (Chrome):** open the link, tap **⋮**, then **Install app** (or **Add to Home screen**).

It opens fullscreen and works offline after the first visit. Hold your phone sideways.

## Controls
| Action | Touch | Keyboard |
|---|---|---|
| Turn | ◀ ▶ buttons | A / D or arrow keys |
| Guns | always firing | always firing |
| Rockets | Rockets button | 1, J or Space |
| Missiles | Missiles button | 2 or K |
| Boost (barrel-roll dodge) | Boost button | Shift, W or Up |
| Pause | II button | Esc |
